# Design Portfolio

A lightweight, responsive, single-page portfolio built with plain HTML and CSS.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository settings on GitHub.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. GitHub will provide the published site URL after deployment.

## Personalize before publishing
- Replace the four sample project tiles and project names with real project images and details.
- Update the About copy to your preferred introduction.
- Replace `your.email@example.com` with your contact email.
- Consider adding individual case-study pages when you have project descriptions ready.

The current project tiles are visual placeholders, not representations of completed client work.
